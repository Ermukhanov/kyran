# Kyran — стратегия и архитектура MVP

*17.11.2026*

## 1. Что делают конкуренты

| Сервис | Рынок | Ключевые фишки | Чего не хватает |
| --- | --- | --- | --- |
| **GovDash** | США | Весь цикл: поиск → оценка → заявка → контракт. Профили рекомендаций, «gate reviews», ИИ пишет заявку | Только США, дорого, веб-платформа для больших команд |
| **Контур.Закупки** | РФ | Умный поиск, ИИ-ассистент отвечает строго по документации **со ссылками на источник**, ИИ-отчёт «участвовать или нет» | Нет Казахстана |
| **Тендервизор** | РФ | Персональный ИИ-разбор под профиль: плюсы/минусы, объём работ, подводные камни. 1–3 мин вместо 30–40 | Нет Казахстана, отдельный сайт |
| **Тендерплан** | РФ | ИИ-прогноз шанса победы, карточка тендера → сделка в CRM, 200+ площадок | Нет Казахстана |
| **Tenderbot.kz** и агрегаторы | КЗ | Платные рассылки тендеров по ключевым словам | Нет ИИ, нет разбора документов, нет воронки |
| **Тендерные специалисты** | КЗ | Ручное сопровождение | Зарплата 400–700 тыс ₸/мес — наш продукт дешевле в 10 раз |

**Вывод.** В РФ и США рынок уже приучен к «ИИ-разбор + воронка». В Казахстане есть только рассылки по словам. Мы переносим лучшие практики и делаем их удобнее за счёт Telegram.

## 2. Чем Kyran лучше (наши фишки)

1. **Живёт в Telegram.** Бот + Mini App с полноценным интерфейсом. Ничего не надо ставить, работает на телефоне и ПК, а через `/web` открывается в любом браузере.
2. **Онбординг без анкеты.** Ввёл БИН → агент сам находит историю закупок компании и предлагает направления (с токеном goszakup).
3. **ИИ-агент, а не бот с кнопками.** Пиши как человеку: «найди ремонт школ до 50 млн и следи за ними». Голосом тоже.
4. **ИИ-разбор с вердиктом:** «Участвовать / Подумать / Пропустить», требования, чек-лист документов, риски, вопросы заказчику.
5. **Оценка 0–100 под профиль** у каждого тендера с объяснением «почему подходит».
6. **Воронка:** Интересно → Готовим → Подали → Выиграли/Проиграли. Тендер не теряется после уведомления.
7. **Мониторинг любого сайта по ссылке**, а не только площадок с API.
8. **Срочные уведомления:** дедлайн ≤ 3 дней — сразу, остальное — утренний дайджест.
9. **Русский и казахский.**

## 3. Архитектура

Один сервис на Railway (FastAPI + Telegram-бот в одном процессе) + PostgreSQL.

```
Источники ──► Сборщик ──► База лотов ──► Подбор (слова → ИИ 0–100) ──► Уведомления
 goszakup API       (каждые N мин)        PostgreSQL                         бот: срочные + дайджест
 любой сайт                                                                   Mini App: лента
 демо (без токена)
                                    Пользователь ──► ИИ-агент (Claude + инструменты)
                                                       ├─ искать лоты
                                                       ├─ разобрать тендер (Sonnet)
                                                       ├─ добавить направление
                                                       └─ следить за сайтом
```

```
app/
├── main.py          # FastAPI: API, Mini App, запуск бота и фоновых задач
├── config.py        # переменные окружения
├── db.py            # модели и сессии (PostgreSQL в проде, SQLite в тестах)
├── sources/         # goszakup, website (любой сайт), demo
├── services/        # matcher, collector, notifier, pipeline
├── ai/              # client, scoring, analysis, agent (у всех — работа без ключа)
├── bot/             # Telegram: онбординг, команды, агент-чат
└── api/             # REST для Mini App + авторизация Telegram
web/                 # Mini App: index.html, app.css, app.js (без сборки)
tests/
```

**Принцип: всё работает без ключей.** Нет `ANTHROPIC_API_KEY` → подбор по словам, разбор недоступен с честным сообщением. Нет `GOSZAKUP_TOKEN` → демо-лоты с пометкой «ДЕМО» (только если `DEMO_MODE=true`), чтобы показывать продукт на встречах.

## 5. Метрики пилота

- Время от `/start` до первого полезного тендера: < 60 секунд.
- ≥ 3 из 5 пилотных компаний открывают разбор хотя бы раз в неделю.
- ≥ 1 тендер в воронке дошёл до «Подали» за 2 недели.
